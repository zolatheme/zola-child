# Zola Child

A starter child theme for the Zola WordPress theme.

## Activate

In WordPress, open **Appearance → Themes** and activate **Zola Child**.

## Customize

- Add CSS rules to `style.css`. Zola automatically loads the child stylesheet after its own theme styles.
- Add PHP hooks or functions to `functions.php`. The parent theme loads first, so its functions are available to the child.
- Keep customizations here instead of editing Zola, so parent theme updates do not overwrite them.
